# Inference service dependencies.

# Pinned to the versions this service was developed and evaluated against. The
# symptom model is a scikit-learn estimator loaded from a joblib file, and
# joblib unpickles it by importing the classes it was trained with — a
# different scikit-learn major version can refuse to load the artifact, or load
# it and behave differently. That artifact is committed to the repo, so the
# version that reads it is pinned alongside it.
#
# scikit-learn and scipy are not imported by app.py directly. They are required
# at runtime all the same: joblib.load reconstructs the estimator, which pulls
# them in. Removing them because nothing references them by name breaks
# startup, not the tests.
